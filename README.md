## 👨‍💻 About Me

I'm a Computer Science student at **Ho Chi Minh City University of Technology (HCMUT)**, interested in embedded software, real-time systems, and intelligent connected devices.

My current learning path focuses on:

- **Embedded C++** — writing structured, maintainable firmware.
- **FreeRTOS** — tasks, queues, semaphores, and real-time behavior.
- **Linux & Operating Systems** — understanding processes, system calls, and low-level software.
- **IoT & Computer Networks** — MQTT, Wi-Fi, and device-to-platform communication.
- **Edge AI** — exploring how AI can run closer to embedded hardware.

My goal is to build a strong foundation in embedded and systems engineering, then combine it with AI to develop practical intelligent devices.
